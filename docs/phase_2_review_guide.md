# Phase 2 review tasks

For OCR review, open `reports/sparse_ocr_review_readable.csv` and compare each candidate against the indicated original PDF and 1-based PDF page. OCR confidence is not a guarantee of accuracy; verify numbers, names, headings, tables, languages and legal wording. Identify blank/cover pages explicitly. OCR output is unreviewed and intentionally excluded from the searchable page registry and indexes. Review does not alter the original PDFs, source IDs or page-document count.

For independent retrieval relevance review, use `evaluation/relevance_review_template.csv`. For each question, inspect the supplied source documents and write all supporting `source_pdf_sha256:page_0001` IDs, not just the first apparently plausible page. Locate original PDFs in `data/raw` by their SHA256 filename; the source registry identifies titles and URLs. Record reviewers and ambiguities. Avoid looking at the provisional gold-page rankings or model answers when making the annotations. The worksheet is not an annotated relevance set until reviewers fill it in and resolve disagreements. Freeze the reviewed annotations before recomputing recall@k and MRR; distinguish incomplete relevance judgments from false positives.

For source metadata, `reports/source_date_review.csv` only searches date strings on the first three extracted pages. 'Not found' does not mean incorrect and 'found' does not establish publication date, current legal status, commencement or a version chain. Inspect official documents and authoritative notifications. `reports/possible_source_versions.json` groups identical normalized titles only; it does not assert supersession or completeness. Date filtering remains disabled pending validation.

For OCR rows accepted after comparison with the original, set `review_status` to `approved`, enter a reviewer name, and correct `ocr_text` in the review sheet if necessary. Run `.venv/bin/python scripts/apply_reviewed_ocr.py` to create a separate reviewed page registry; this does not rebuild or change the current retrieval indexes. Record rejected or blank pages separately. Obtain legal and language review appropriate to the source before trusting OCR text.

The 11 scanned Social Security pages now also have `reports/ocr_11_page_comparison.csv`, which shows the first OCR, a proposed draft, a second OCR, and flags. `source_page_copy` points to a single-page copy of the scan (the copy displays page 1; `pdf_page_number` gives the original number). All 11 pages now have agent-transcribed drafts checked against page images; all remain unapproved and require independent review. After checking a page against the scan, transfer the verified text to the corresponding `ocr_text` cell in `reports/sparse_ocr_review_readable.csv` and record the reviewer and approval there. Never infer or silently repair an apparent error printed in an original source.
