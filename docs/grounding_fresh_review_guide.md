# Review the new document-grounding test set

The 20 cases are a draft. They have not been sent to the hosted model. Questions ask what the cited source says; do not assume that a historical document alone establishes current legal applicability. They cover five original sources and 14 distinct original PDF pages. The automated duplicate check found no exact question match in the frozen `gold_v1` set; wording and subject similarity have not received independent semantic review. The set was authored with knowledge of the corpus by the implementer, so it is not a large or fully independent statistical sample.

Open `reports/grounding_fresh_review_guide.md` for each question, expected answer, cited page and a link to a one-page copy of the original. The copy shows page 1 in a PDF viewer; the guide identifies the original PDF page number. Case fresh-draft-020 is based on a user-accepted OCR transcription; table separators in the transcript are not literal text printed on the image, so check the scan. Case fresh-draft-007 has supporting text on original PDF pages 8 and 9. The full proviso for fresh-draft-013 appears on PDF page 41; its previous truncation was caused by our excerpt boundary.

Open `evaluation/grounding_fresh_review.csv` to record review. For each row, confirm that the question is clear and non-duplicative, the expected conditions are complete and supported by the source, and the quoted passage refers to the correct PDF/page. The supplied audit recommends 17 rows as `approved` and flags three for follow-up; these statuses are recommendations until a reviewer identifies themselves. If correct, enter `approved` in `review_verdict` and the reviewer's name in `reviewer`. If not, enter `needs_changes` and explain in `review_notes`. The question and expected conditions can be edited in the CSV; the quote must remain an exact passage from the registered page (or the accepted OCR transcription, where flagged). Source title, URL and page changes require a corrected source reference in the draft before freezing. Do not enter real employee details.

Only after every row is approved by an identified reviewer, run `python scripts/freeze_grounding_review.py`. It verifies identities, page metadata, exact page text and duplicates, and refuses to overwrite a frozen version. The resulting JSONL and SHA256 are immutable; use a new version for later corrections. The separate `gold_v1` and its recorded baseline scores remain unchanged. Do not run the hosted model on the draft before review and freeze.

After freezing, `scripts/evaluate_fresh_grounding.py` can run the reviewed questions through the accepted-OCR hybrid index and opt-in review-only workflow. It checks the frozen set's checksum, reviewer fields, index content, workflow code fingerprint and cache coverage before running. It records retrieval ranks, model decisions, cited text, latency and usage; it does not score answer correctness or release model-generated answers automatically. It supports resuming only an identical configuration. Use `python scripts/evaluate_fresh_grounding.py --help` to supply local chat and embedding key-file paths, CA paths, endpoints and model IDs; never paste key contents into arguments or reports. After all cases complete, `python scripts/prepare_fresh_result_review.py` creates an unscored human-review CSV and refuses to overwrite an existing sheet. Most cases have one recorded source page; fresh-draft-007 has two. These are not exhaustive independently labeled retrieval sets.
